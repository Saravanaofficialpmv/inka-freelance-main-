## ✨ Key Features

- **⚡ Lightning-Fast Invoicing**: Create itemized invoices with clients, taxes, and discounts in under 30 seconds.
- **📄 10+ Vector PDF Templates**: Professional A4 layouts (Modern, Professional, Legend e-Invoice, Compact, Evergreen, etc.).
- **💳 Dynamic UPI QR Payments**: Embeds dynamic `upi://pay` QR codes directly on invoices for instant payment collection.
- **⏱️ Integrated Time Tracker**: Built-in stopwatch and manual hour logging with one-tap conversion to billable invoices.
- **📈 Expense & Profit Management**: Track business expenses by category and view live net profit margins.
- **✍️ Digital Signatures**: Interactive touch drawing pad for authenticating invoices.
- **🌐 Multilingual**: Dynamic runtime language switching between English (`en`), Tamil (`ta`), Hindi (`hi`), and Spanish (`es`).
- **📱 Responsive Layout**: Seamless mobile navigation shell and persistent desktop/web sidebar.

## 🚀 Quick Start

1. **Install Dependencies**:
   ```bash
   flutter pub get
   ```

2. **Generate Adapters**:
   ```bash
   flutter pub run build_runner build --delete-conflicting-outputs
   ```

3. **Run Application**:
   ```bash
   flutter run
   ```

4. **Execute Tests**:
   ```bash
   flutter test
   ```
